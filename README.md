# Host de Exploits para PS4

**Firmwares compatíveis:** `5.05` `6.72` `7.XX` `8.XX` `9.XX` `10.XX` `11.XX` `12.XX` `13.XX` `14.00` `14.02`

## Instruções

- No navegador do PS4, acesse: https://rayzenx9.github.io
- Selecione a versão do firmware do seu console.
- O conteúdo será instalado automaticamente no cache offline. Quando a instalação terminar, feche o navegador e desative a conexão com a internet.
- Depois, abra o navegador novamente e aproveite!
